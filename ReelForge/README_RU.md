# ReelForge — мобильный автомонтаж рилсов

Исходники MVP для iPhone и Android. Это не готовые IPA/APK и не проверенный магазинный релиз.

## Реализовано в коде

- Общий мобильный интерфейс React Native / Expo: выбор видео из галереи, музыки из файлов, шаблона, длительности, качества.
- Музыкальный монтаж: нарезка по сетке BPM с подстройкой к звуковым акцентам. BPM задаёт пользователь; полноценного определения музыкальных долей нет.
- 5 шаблонов: Clean Cut (fade), Velocity (плавное ускорение/замедление и сдвиг), Flash Pop (белая вспышка), Cinema (затемнение и цвет), Zoom Flow (zoom и изменение скорости).
- Плавное изменение скорости примерно 0.625×–2.5×; без оптической интерполяции кадров.
- Разговорный режим: один исходник; faster-whisper распознаёт речь, вырезаются промежутки между распознанными фразами, добавляются субтитры группами по 4 слова с fade-анимацией. Паузы внутри фраз могут остаться.
- Экспорт MP4 H.264/AAC, 9:16, 720p или 1080p, 30 fps. Центрирование с обрезкой до вертикального кадра.
- Статус фонового задания на сервере, восстановление опроса после перезапуска приложения, просмотр результата и системное меню сохранения/отправки.
- Bearer-ключ, сохранение ключа на телефоне через SecureStore, удаление исходников после обработки, ручное удаление результата с сервера.

## Архитектура и ограничения

Телефон загружает исходники на ваш ПК или сервер. FFmpeg монтирует ролик, faster-whisper распознаёт речь. Обработка не работает без сервера. Интернет нужен для первой загрузки Whisper-модели; после её кеширования распознавание локальное на сервере.

Это личный сервер для одного владельца, а не многопользовательский облачный сервис. Не выставляйте его напрямую в публичный интернет: используйте частную сеть или HTTPS с ограничениями запросов/загрузки на reverse proxy. Серверный ключ даёт доступ ко всем его заданиям.

Стартовые шаблоны используют распространённые приёмы монтажа; актуальность трендов не проверена. Автообновление каталога, импорт шаблонов CapCut, ручной таймлайн, выбор лучших моментов по смыслу, анимированные стикеры, трекинг лица и motion blur отсутствуют. Имеются анимированные переходы и появление субтитров.

Музыкальный режим использует начало каждого клипа по очереди и повторяет короткие исходники, если нужно. Звук исходных видео заменяется музыкой. Результат ограничен длиной музыки. Разговорный режим использует только первый клип и сохраняет его звук; настройки визуального шаблона могут менять цвет, но переходы между фразами — прямые склейки.

Загрузка требует открытого приложения. После приёма задания сервер работает независимо от телефона. Очередь хранится в памяти: перезапуск сервера теряет статусы. Завершённые MP4 остаются на диске до удаления. Для восстановления подключения после смены сервера потребуется перезапуск приложения/очистка сохранённого задания в SecureStore. Фоновая загрузка iOS не реализована.

## 1. Сервер на ПК

Установите Docker Desktop. В каталоге `ReelForge` создайте `.env`:

```dotenv
REELFORGE_TOKEN=replace-with-a-long-random-secret
```

Сгенерировать ключ: `python -c "import secrets; print(secrets.token_urlsafe(32))"`.

Запуск:

```sh
docker compose up --build -d
```

Сервер слушает порт 8787. Контейнер включает FFmpeg и шрифт для субтитров. Модель Whisper `small` скачивается при первом разговорном монтаже, что может занять время. Языки: авто, русский, английский, казахский, узбекский, турецкий, французский. Качество зависит от языка и записи; редактора исправления текста в MVP нет.

Без Docker: установите Python 3.11/3.12 и FFmpeg с libass, перейдите в `server`, установите зависимости и задайте ключ:

```sh
pip install -r requirements.txt
# macOS/Linux:
export REELFORGE_TOKEN='your-long-random-secret'
uvicorn app:app --host 0.0.0.0 --port 8787 --workers 1
```

PowerShell вместо `export`: `$env:REELFORGE_TOKEN='your-long-random-secret'`.
Для Windows проверьте наличие шрифта DejaVu Sans либо замените шрифт в `engine.py`.

## 2. Мобильное приложение

Требуются Node.js LTS и доступ к npm. В архиве уже есть подготовленный Expo-проект с зафиксированными npm-зависимостями:

```sh
cd mobile/reelforge-app
npm ci
npx expo start
```

Для создания другого чистого проекта предусмотрен `mobile/bootstrap.mjs`; он используется только когда папки `reelforge-app` ещё нет. При сбое сети после создания папки продолжите установку модулей через `npx expo install expo-video expo-image-picker expo-document-picker expo-file-system expo-sharing expo-secure-store` в ней, затем выполните `node configure.mjs` из `mobile`.

Откройте проект на телефоне через совместимый Expo Go или development build. Укажите адрес сервера и ключ в настройках. Телефон должен видеть сервер по сети. `localhost` на телефоне означает сам телефон, а не ПК. Для сборок используйте HTTPS; разрешение локальной сети iOS включено, универсальное разрешение незашифрованного HTTP в релизе не включено.

`mobile/App.tsx` — исходный экран, который bootstrap копирует в созданный проект. После запуска редактируйте `mobile/reelforge-app/App.tsx`.

## 3. APK / iOS

В каталоге созданного Expo-проекта:

```sh
npx eas-cli@latest login
npx eas-cli@latest build:configure
npx eas-cli@latest build --platform android --profile preview
npx eas-cli@latest build --platform ios --profile preview
```

Для iOS потребуются учётная запись Apple Developer, подпись и регистрация устройства для внутренней установки. Для Android профиль preview формирует APK. Перед публикацией задайте собственные bundleIdentifier/package вместо `app.reelforge.mobile`. Аккаунт EAS и подписи пользователь настраивает самостоятельно; в этом архиве сертификатов нет.

## Проверка

На текущей среде выполнен реальный рендер FFmpeg для всех пяти шаблонов: выход 720×1280, аудиодорожка, длительность около 5 секунд. Отдельно проверены склейки со звуком и встраивание кириллических ASS-субтитров.

```sh
python tests/test_render.py
```

Проверка TypeScript выполнена без ошибок. Установка npm-зависимостей завершена.

Не выполнены: нативная сборка iOS и Android, проверка на физических телефонах, полное распознавание Whisper с загрузкой модели, нагрузочное тестирование. Статус HTTP-проверок указан в `VALIDATION.txt`. Не следует считать исходники готовым приложением до этих проверок.

4. Перенести обработку на устройство отдельными движками iOS/Android, если нужен монтаж без ПК/сервера.
5. Перед массовым использованием: пользователи, изоляция файлов, постоянная очередь, квоты и сроки хранения.
