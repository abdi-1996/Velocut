# ReelForge 0.2 — монтаж на телефоне

Версия 0.2 заменяет серверную обработку встроенным видеодвижком. Для монтажа не нужен ПК, адрес сервера, ключ или загрузка видео в облако.

Откройте приложение, выберите клипы и музыку, шаблон и длительность. Нажмите «Создать рилс». После экспорта можно посмотреть MP4 и сохранить его через системное меню. Во время экспорта держите приложение открытым. Экран автоматически не гаснет на iPhone.

## Возможности

- 5 встроенных шаблонов: мягкие переходы, speed ramp со сдвигом, белые вспышки, затемнение, zoom.
- 15/30/60 секунд, 720×1280 или 1080×1920, 30 кадров/с.
- Подстройка склеек к звуковым акцентам возле сетки BPM. BPM задаётся вручную.
- В музыкальном режиме используется начало клипов по очереди; короткие исходники повторяются. Звук клипов заменяется выбранной музыкой.
- Плавно меняющаяся скорость примерно 0.5×–2×, без оптической интерполяции.
- Разговорный режим сокращает тихие паузы; с автосубтитрами — промежутки между распознанными словами. Шум/музыка в исходнике могут ухудшить определение пауз.
- Ручные титры: каждая строка показывается последовательно, одинаковое время.
- Автосубтитры iOS используют только on-device Speech. Если офлайн-модели языка нет или доступ запрещён, предлагается ручной текст/режим без текста. Нет облачного fallback.
- Отмена монтажа, локальное хранение результата и восстановление последнего ролика после открытия приложения.

## Ограничения

Видео кадрируется по центру до 9:16. Нет ручного таймлайна и умного выбора лучших моментов. Это встроенная коллекция, а не автоматически обновляемый каталог трендов. При недостатке места/оперативной памяти экспорт может завершиться ошибкой; попробуйте 720p и короткий ролик. Исходники из iCloud сначала должны быть скачаны на телефон системным выбором медиа.

Неподписанный IPA необходимо подписать для установки. Встроенный модуль требует нативной сборки; Expo Go его не содержит.

Основной исходник приложения: `mobile/reelforge-app`. Нативные движки: `modules/reel-renderer` внутри него. Старая папка `server` оставлена как история версии 0.1 и в приложении 0.2 не используется.

## Разработка

```sh
cd mobile/reelforge-app
npm ci
npx expo prebuild
```

iOS: workflow `.github/workflows/reelforge-ios.yml` в ветке `reelforge-ios`. Сборка включает TypeScript и нативные проверки экспорта на iOS Simulator. Физический iPhone нужен для проверки разрешений, реальных HEVC/HDR-файлов, производительности и наличия офлайн-распознавания.
