# CHANGELOG

## Version 0.6.3

### Added
- DaVinci Resolve-inspired Cut timeline for iPhone and iPad.
- Fixed center playhead: horizontal scrubbing moves the timeline under the playhead instead of dragging the playhead away.
- Direct video/audio/FX/text lanes without the redundant summary track above them.
- Edge trim handles on the selected video clip.
- Contextual Cut toolbar with Trim, Split, Delete, Speed, Volume and Duplicate.
- Main editor toolbar for Media, Audio, Text, Effects, Transitions, Filters and Adjust.
- Timeline timecode and zoom controls.

### Changed
- Removed the left track rail from Cut mode to give more width to the editing canvas.
- Increased selected clip height and touch targets for easier finger editing.
- Preserved the existing AVFoundation editing/export engine and project functions from 0.6.2.

## Version 0.6.2

### Added
- Reference dark editor interface.
- Grouped video/audio/text/FX workflow.
- Timeline track management and contextual audio controls.

### Fixed
- Fresh editor UI compile issues.
